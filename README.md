# Python Mini Games

A collection of small command-line games I built in Python to practice fundamental programming concepts and game logic.

### 🪨 Rock, Paper, Scissors (`rock_paper_scissors.py`)
A 5-round match against the computer with score tracking and basic terminal formatting.

* **Key concepts:** `while` loops, conditional logic, string methods (`.lower()`), `random` module

### 🎯 Number Guessing Game (`number_guessing_game.py`)
Try to guess a secret number between 1 and 100 using "higher" or "lower" hints along the way.

* **Key concepts:** `while` loops, conditional checks, integer casting (`int()`), `random` module

### 🚀 How to Run

1. Make sure Python is installed.
2. Open your terminal in this folder and run whichever game you want:

```bash
python rock_paper_scissors.py
# or
python number_guessing_game.py
