# ⚡ Python To-Do App

A clean, interactive To-Do application built with Python and Streamlit, featuring real-time JSON data persistence, visual progress tracking, and interactive task management.

---

## 📋 Prerequisites & Installation

### 1. Requirements
- **Python 3.8+** installed on your computer.

### 2. Install Required Packages
Open your terminal or command prompt and run:
```bash
pip install streamlit

🚀 How to Run the App
Navigate into the project directory:
cd todo_app

Write "streamlit run app.py" to run the app.
